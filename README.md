## Introduction
Hello, We built EndoCore as an interactive, browser-based 3D digital twin to tackle one of the biggest challenges in curing Type 1 Diabetes: replacing toxic systemic immunosuppressants with localized immunomodulation. 

Instead of just writing about our proposed biohybrid nanochip, we decided to code a fully interactive WebGL simulation so you can actually see how it works. We built this from scratch using **Three.js** and **JavaScript (ES6)** and AI modules help in programming.

## 🚀 What You Can Do in the Live Demo
We designed this MVP to be fully interactive so you can explore the system's capabilities firsthand. Here are a few key features:
- **Look Around:** You can rotate 360° around the nanochip, Islets of Langerhans, and swarming CD8+ T-cells.
- **Run the Stress Test:** Click "Simulation 1" to run our automated autoimmune attack. You'll see the AI release IL-10/TGF-β to save the beta cells.
- **Watch the Data:** The right-side dashboard shows live TinyML risk probability, insulin output, and peptide reservoir levels.

## 🏗️ The 5-Layer Hardware
If you double-click the 3D capsule (or click the left-side button), the device explodes into the 5 layers we designed:
1. **Zwitterionic Hydrogel Coat:** Our anti-fibrotic outer shield.
2. **Nanoporous Membrane & β-Cells:** Where we house the CRISPR-edited cells.
3. **Electrochemical Nano-Sensors:** The gold beads that detect IL-6, IFN-γ, and pH drops.
4. **TinyML Edge-AI Processor:** The brain of the chip.
5. **Peptide Reservoirs & Power Coil:** The micro-valves for peptide release and inductive charging.

## 🔒 A Note on Data Privacy (PDPL)
Since we are dealing with biological data, we made sure the architecture complies with Saudi PDPL regulations. We locked down the privacy using three strict rules:
1. **Local Edge AI:** We process all metabolic data locally on the chip in <50 ms. Nothing goes to the cloud.
2. **One-Way Hardware:** Our inductive coil only receives power; it never broadcasts vitals out.
3. **Hermetic Isolation:** We don't use Wi-Fi or Bluetooth, so the device cannot be hacked remotely.
