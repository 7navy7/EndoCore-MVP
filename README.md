## Overview

EndoCore is a proposed biohybrid nanochip for Type 1 Diabetes: an implantable pod holding CRISPR-edited beta cells behind a nanoporous membrane, with electrochemical sensors that watch the local microenvironment and micro-reservoirs that release tolerogenic peptides (IL-10, TGF-β) *locally* when an autoimmune attack begins. The goal is to replace toxic systemic immunosuppressants with localized immunomodulation.

This repository contains the **in-silico MVP**: a browser-based 3D digital twin of the device and its microenvironment, plus the training pipeline for the edge-AI classifier that drives it.

## Data & tools, and the role each one plays

### Data

There is **no patient data, no in-vitro data and no in-vivo data** in this project. The training dataset is fully synthetic and generated by `generate_synthetic_dataset.py`, which is checked into this repository so the data can be audited and reproduced exactly (the seed is fixed).

The generator draws from physiological anchors taken from the literature cited in our submission: homeostasis at IL-6 ≈ 4 pg/mL, IFN-γ ≈ 3 pg/mL, pH 7.40 and no infiltrating T-cells; acute attack at IL-6 and IFN-γ of 40–100 pg/mL, pH below 6.95, and 48–60 CD8+ T-cells. It samples four named physiological states plus a uniform sweep of the entire sensor operating range, so the classifier is defined everywhere a judge can drag a slider, not only near the clusters.

Labels come from a latent severity score combining all four signals, with a stochastic term added before thresholding. That noise term is deliberate and is documented in the source: without it the classes separate perfectly, the fitted coefficients blow up, and the model jumps from 0% to ~96% risk over a narrow band — useless as an early warning. The noise level is calibrated so the model still separates well (ROC-AUC ≈ 0.985) while producing a progressive risk ramp.

### Why logistic regression, not a larger model

The target is a microcontroller inside a sealed implant. Inference must be deterministic, auditable and cheap: the fitted model is four coefficients and an intercept, fits in a few hundred bytes of flash, and runs in microseconds — far inside the <50 ms budget claimed for Layer 4. A tree ensemble would be larger, harder to audit, and would produce the step-function output that is wrong for a dosing decision. We want a *graded* risk probability, not a hard yes/no.

## Testing & validation

### What we tested

Whether a closed-loop control architecture — sense IL-6 / IFN-γ / pH / CD8+ infiltration → classify risk on-device → actuate peptide release → restore homeostasis — is internally consistent, and whether a classifier small enough for the implant can separate an acute autoimmune flare from a quiet microenvironment across the full sensor operating range.

### How we tested it

6,000 synthetic samples, split 75/25 stratified. Stratified 5-fold cross-validation on the training split; all headline numbers reported on the held-out test set at the deployed decision threshold of 0.35.

### Results

Reproduce with `python tinyml_training_backend.py`; full output in [`validation_report.txt`](validation_report.txt).

```
5-fold CV accuracy : 0.9411 +/- 0.0058
5-fold CV ROC-AUC  : 0.9845 +/- 0.0026

Held-out test set (1,500 samples, threshold 0.35)

                    predicted None   predicted Release
  actual None                  732                  49
  actual Release                40                 679

  Sensitivity (attack detected)       : 0.9444
  Specificity (quiet state preserved) : 0.9373
  Precision (PPV)                     : 0.9327
  Negative predictive value           : 0.9482
  Accuracy                            : 0.9407
  ROC-AUC                             : 0.9854
```

Behaviour at the states the demo plays:

| State | Predicted risk | Micro-valves |
|---|---|---|
| Homeostasis (IL-6 4, IFN-γ 3, pH 7.40, 0 cells) | 0.97% | closed |
| Early Stage 1–2 infiltration | 4.59% | closed |
| Mid-ramp flare | 86.32% | **release** |
| Acute attack peak | ~100% | **release** |

A note worth making: the coefficients the model learned (intercept −5.03; IL-6 0.0592, IFN-γ 0.0537, pH-drop 2.751, CD8+ count 0.0375) landed very close to the weights we had originally reasoned out by hand. The training run independently corroborated our design assumptions rather than overturning them.

### ⚠️ What these results are NOT

These metrics measure **the control logic on synthetic data**. They are not evidence of biological efficacy, sensor accuracy, or clinical benefit. Synthetic data cannot validate biology — it can only show that the decision architecture is coherent and that the on-device model is small enough and stable enough to run.

### What remains untested

- Wet-lab calibration of the 16-node electrochemical sensor array in simulated interstitial fluid.
- In-vitro co-culture of CRISPR-edited beta cells with human CD8+ T-cells to verify IL-10 / TGF-β Treg conversion.
- Physical MEMS fabrication, micro-valve dosing accuracy, and reservoir longevity.
- Anti-fibrotic performance of the zwitterionic hydrogel coat in living tissue.
- Any in-vivo preclinical work. No animal or human testing has been done.
- Classifier performance on *real* sensor data. Every number above would need to be re-measured.

## Feasibility & key risks

| Risk | Mitigation in the current design |
|---|---|
| Pericapsular fibrosis fouling the sensors | Zwitterionic-silicone hydrogel outer dome, selected from the anti-fibrosis literature cited in the deck |
| Off-target CRISPR edits / teratoma formation | Whole-genome sequencing and FACS pre-sorting *ex vivo*, with physical containment inside the <30 nm pod |
| Peptide thermal degradation and reservoir depletion | Lyophilized storage in hermetically sealed micro-reservoirs; onboard impedance level sensing; transdermal microneedle replenishment |
| Data privacy (Saudi PDPL) | All inference runs on-device; the inductive coil receives power only and never transmits; no Wi-Fi or Bluetooth interface exists, so there is no remote attack surface |

The largest *technical* risk is not in this repository at all: it is whether the sensor array can resolve these cytokine ranges reliably in living interstitial fluid. Everything downstream depends on that, and it is the first thing we would test.

### Regulatory pathway

**Classification**
- EndoCore is a Class III implantable medical device combining a drug (IL-10 / TGF-β), a biologic (allogeneic gene-edited cells), and software (edge-AI). In Saudi Arabia it falls under SFDA medical device regulation; a combination product of this type requires the most stringent evidence pathway.

**What that means for us**
- We are at **TRL 3–4**: the concept and the control algorithm are validated *in silico*; nothing has been fabricated or tested biologically.
- The next regulatory step is not approval, but an **SFDA pre-submission consultation** to agree on the evidence package before wet-lab work begins.
- **IRB approval** is required before any work involving human cells.

**Evidence we would still need**
- Biocompatibility (**ISO 10993**) for the hydrogel and membrane.
- Sterility and shelf-life validation for the lyophilized peptide reservoirs.
- Software lifecycle documentation (**IEC 62304**) and an algorithm change-control plan for the edge-AI.
- *In vitro* co-culture, then *in vivo* preclinical safety, then a 3–10 patient first-in-human study.

## Running it yourself

**The simulation** — open `index.html` in any modern browser, or visit the live demo link above. No build step.

**Retraining the classifier:**

```bash
pip install -r requirements.txt
python generate_synthetic_dataset.py    # -> synthetic_cytokine_dataset.csv
python tinyml_training_backend.py       # -> endocore_model.{json,js}, validation_report.txt
```

`tinyml_training_backend.py` writes `endocore_model.js`, which `index.html` loads directly. Retraining therefore changes what the simulation does — there is no separate copy of the weights to keep in sync.
